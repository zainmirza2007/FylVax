# Fylvex UI/UX direction

Version 2 uses a tool-first interface designed for both desktop and mobile.

## Principles

- Put the exact task, uploader, supported formats, settings, and primary action before SEO content.
- Keep the core workflow short: upload → choose settings → process → download.
- Use progressive disclosure for advanced settings instead of showing technical controls to everyone.
- Keep advertisements outside the upload/processing control area, with deliberate spacing before any ad slot.
- Keep private processing and result states ad-free and `noindex`.
- Use original, task-specific explanatory sections below the tool: practical use cases, limitations, common targets when relevant, workflow, privacy, FAQ, and related tools.
- Mobile layouts use large controls, one-column tool cards, responsive trust panels, and no horizontal scrolling.
- No external font dependency is required for the core UI.

## Visual system

- Primary: indigo (`#5b5cf0`)
- Backgrounds: white and very light neutral/lavender sections
- Borders are used more often than heavy shadows so the utility stays calm and minimal.
- Category glyphs use distinct soft backgrounds without relying on external icon libraries.

## Search and discovery

The homepage includes a lightweight client-side tool search. Category hubs and exact-intent tool pages remain the primary crawlable architecture. Search results do not create indexable query pages.
